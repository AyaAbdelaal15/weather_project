# 🌤️ WeatherApp

A responsive weather application built with **HTML5, CSS3, and JavaScript**.

The application allows users to search for a city and view current weather information along with forecast details in a clean and responsive interface.

🔗 **Live Demo:**

---

## 📌 Project Overview

**WeatherApp** is a frontend weather application developed to practice working with:

- JavaScript
- APIs
- Asynchronous operations
- DOM manipulation
- Responsive web design
- Dynamic data rendering
- Search functionality

The project provides weather information for different cities through a simple and user-friendly interface.

---

## ✨ Features

- 🌍 Search for weather by city name
- 🌡️ Display current temperature
- ☁️ Show current weather condition
- 💧 Display humidity information
- 💨 Display wind information
- 📅 Weather forecast
- 🔎 Dynamic search functionality
- 📱 Fully responsive design
- 🎨 Clean and modern user interface
- ⚡ Dynamic content rendered using JavaScript
